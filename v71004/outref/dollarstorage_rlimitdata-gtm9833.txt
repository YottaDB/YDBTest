# ********************************************************************************************
# GTM-9833 - Test the following release note
# ********************************************************************************************
# 
# Release note (from http://tinco.pair.com/bhaskar/gtm/doc/articles/GTM_V7.1-004_Release_Notes.html#GTM-DE197637833)
# 
# $STORAGE reports the correct value when there is a restriction on the data segment limit (RLIMIT_DATA) of a process. Previously, $STORAGE inappropriately returned 2GiB in such a case. (GTM-9833)
# 

# Test that $STORAGE returns the correct value, based on the current RLIMIT_DATA (data segment size) limit.
# Running  [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!'] consumes about 680kB
# of memory. So, $STORAGE should return the specified RLIMIT_DATA limit minus about 680kB.

# Case 1: Set process data segment size (RLIMIT_DATA) to 2048
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 1470873 and 1330790
##TEST_AWKPASS: \$STORAGE=13[0-9]*

# Case 2: Set process data segment size (RLIMIT_DATA) to 4096
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 3672883 and 3323084
##TEST_AWKPASS: \$STORAGE=34[0-9]*

# Case 3: Set process data segment size (RLIMIT_DATA) to 16384
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 16884940 and 15276851
##TEST_AWKPASS: \$STORAGE=16[0-9]*

# Case 4: Set process data segment size (RLIMIT_DATA) to 32768
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 34501017 and 31215206
##TEST_AWKPASS: \$STORAGE=32[0-9]*

# Case 5: Set process data segment size (RLIMIT_DATA) to 65536
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 69733171 and 63091916
##TEST_AWKPASS: \$STORAGE=66[0-9]*

# Case 6: Set process data segment size (RLIMIT_DATA) to 131072
# Run [$gtm_dist/mumps -r %XCMD 'write $STORAGE,!']
# Expect $STORAGE to be between 140197478 and 126845337
##TEST_AWKPASS: \$STORAGE=13[0-9]*
