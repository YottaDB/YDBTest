# Release note (from http://tinco.pair.com/bhaskar/gtm/doc/articles/GTM_V7.1-004_Release_Notes.html#GTM-DE1959410099)

# GT.M uses TPNOTACID behavior for all external calls and for ZEDIT; previously, external calls and the ZEDIT command were exempted from TPNOTACID handling. (GTM-10099)
# 

### Test 1: ZEDIT in the final retry of a transaction sends a TPNOTACID warning to the syslog
# Run [gtm10099.m], which restarts a transaction 3 times and then runs ZEDIT
# Expect a TPNOTACID warning for ZEDIT. Previously, ZEDIT sent no TPNOTACID message.
%GTM-W-TPNOTACID, ZEDIT at trans+4^gtm10099 violates ACID properties of a TRANSACTION and could exceed 2000 milliseconds; 3 RESTARTs have occurred

### Test 2: An external call in the final retry of a transaction sends a TPNOTACID warning to the syslog
# Run [gtm10099.m], which restarts a transaction 3 times and then calls the gtm10099() C function
# Expect EXT CALL from the function, and a TPNOTACID warning for the call. Previously, an external call sent no
# TPNOTACID message.
EXT CALL
%GTM-W-TPNOTACID, CALL OUT at trans+6^gtm10099 violates ACID properties of a TRANSACTION and could exceed 2000 milliseconds; 3 RESTARTs have occurred
