# [YDB#1286] $ZWRITE(str,1) and ydb_zwr2str_s() return the empty string for a str that is not a      #
# complete ZWRITE format string, and do not read past its end                                        #
#----------------------------------------------------------------------------------------------------#

# zwr2format() converts a ZWRITE format string to the string it represents, for $ZWRITE(str,1),
# ydb_zwr2str_s(), MUPIP LOAD and trigger definitions. It read the byte after a string that ended
# in "$", "$Z", "$ZC", "$C", or after the number in an unterminated $C( or $ZCH(. It also accepted
# strings ending in "_", in an unterminated quoted string, in an unterminated $C( or $ZCH(, or in a
# number that does not end in a digit.
#
# $EXTRACT() and $ZEXTRACT() return a string that shares memory with their source, so a prefix of a
# ZWRITE format string taken that way is followed in memory by the rest of the string, and a read past
# its end finds the byte that makes it valid. In stage 5 a read past the end gets a SIGSEGV.
#
# Without the fix, every check below prints WRONG except the controls, whose expected result is not
# the empty string, and the invalid strings "X"_$C(65)Y and _"X". In stage 5 the six strings in the
# first group each end the process with a SIGSEGV.

# Stage 1 : prefixes of a valid ZWRITE format string, taken with $EXTRACT()
# Command : $ydb_dist/yottadb -run truncated^ydb1286
#   expect "" for each prefix that ends in "$", "$Z", "$ZC", "$C" or an unterminated $C( or $ZCH(, and
#   "XA" for the complete strings
PASS : $zwrite(y,1) with y="X"_$, the first 5 characters of "X"_$C(65) returned ""
PASS : $zwrite(y,1) with y="X"_$Z, the first 6 characters of "X"_$ZCH(65) returned ""
PASS : $zwrite(y,1) with y="X"_$ZC, the first 7 characters of "X"_$ZCH(65) returned ""
PASS : $zwrite(y,1) with y="X"_$C, the first 6 characters of "X"_$C(65) returned ""
PASS : $zwrite(y,1) with y="X"_$C(65, the first 9 characters of "X"_$C(65) returned ""
PASS : $zwrite(y,1) with y="X"_$ZCH(65, the first 11 characters of "X"_$ZCH(65) returned ""
PASS : $zwrite(y,1) with y="X"_$C(65), the first 10 characters of "X"_$C(65) returned "XA"
PASS : $zwrite(y,1) with y="X"_$ZCH(65), the first 12 characters of "X"_$ZCH(65) returned "XA"
