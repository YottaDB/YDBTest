#----------------------------------------------------------------------------------------------------#
# [YDB#1333] A process exits cleanly when $ZTEXIT is true and a transaction is active               #
#----------------------------------------------------------------------------------------------------#

# The exit handling rolls back an active transaction. With $ZTEXIT true, that TROLLBACK issued an
# error so that a deferred $ZINTERRUPT could run, which aborted the rest of the exit handling.

# Stage 1 : SET $ZTEXIT=1, TSTART (), HALT
# Before the fix : LKRUNDOWN and exit status 242
# With the fix   : expect the process to exit with status 0 and no output
# Command : $gtm_dist/mumps -run ztexithalt^ydb1333
PASS : exit status 0 and no output

# Stage 2 : LOCK ^ydb1333, SET $ZTEXIT=1, TSTART (), HALT, while another process has the database
#           open
# Before the fix : LKRUNDOWN and exit status 242, and the LOCK stayed in the lock space, owned by the
#                  exited process
# With the fix   : expect the process to exit with status 0 and no output, and no LOCK left in the
#                  lock space
# Command : $gtm_dist/mumps -run ztexitlock^ydb1333
PASS : exit status 0 and no output
# Command : $gtm_dist/lke show -all, which reports a LOCK of an exited process without removing it
PASS : no LOCK is left in the lock space

# Stage 3 : SET $ZTEXIT=1, TSTART (), TROLLBACK, without exiting
# Before the fix : $ZINTERRUPT ran after the TROLLBACK (this stage is a control)
# With the fix   : expect $ZINTERRUPT to run after the TROLLBACK, and $TLEVEL 0
# Command : $gtm_dist/mumps -run ztexitrollback^ydb1333
$ZINTERRUPT ran, $tlevel=0
after TROLLBACK $tlevel=0

# Stage 4 : SET $ZTEXIT=1, TSTART (), SET, TCOMMIT, without exiting
# Before the fix : $ZINTERRUPT ran after the TCOMMIT (this stage is a control)
# With the fix   : expect $ZINTERRUPT to run after the TCOMMIT, $TLEVEL 0, and the SET committed
# Command : $gtm_dist/mumps -run ztexitcommit^ydb1333
$ZINTERRUPT ran, $tlevel=0
after TCOMMIT $tlevel=0 ^ydb1333commit=1

# Done
