#----------------------------------------------------------------------------------------------------#
# [YDB#1327] TP restart after an argumentless or exclusive NEW that follows TSTART                   #
#----------------------------------------------------------------------------------------------------#

# A TRESTART, or an implicit restart, of a transaction after an argumentless or exclusive NEW that
# follows its TSTART failed with GTMASSERT2 or a SIG-11 when the TSTART and the NEW were in the same
# XECUTE. Now the restart works as it does in a routine. In Direct Mode, which has no frame of its own
# for the symbol table of the NEW, the restart now issues TRESTNEW and TRESTLOC instead, and leaves the
# transaction as it was. And an argumentless NEW in Direct Mode after a BREAK moved the M stack
# without adjusting the pointers the transaction keeps into it, which stages 5 to 7 check.
#
# Each case of stages 1 and 2 runs in its own process. It records the local variables it sees in the
# transaction after the restart and after the transaction, compares them with the values the restart
# rules give, and prints PASS or WRONG.

# Stage 1 : TSTART and an argumentless or exclusive NEW in the same XECUTE, then a restart
# Before the fix, each case except xn2, whose NEW is in an inner XECUTE, ended with GTMASSERT2 in tp_restart.c
# (or a SIG-11, depending on the layout of the routine), and xn2 passed
#   expect the restart to restore the local variables and undo the NEW
# Command : $gtm_dist/mumps -run one^ydb1327 xa
PASS : xa : XECUTE: TSTART (x), argumentless NEW, TRESTART
       in the transaction, then after it : 10 1|2 0
# Command : $gtm_dist/mumps -run one^ydb1327 xi
PASS : xi : XECUTE: TSTART (x,z), NEW (x), TRESTART (x z $TRESTART, then x z $TLEVEL)
       in the transaction, then after it : 10 <undef> 1|10 6 0
# Command : $gtm_dist/mumps -run one^ydb1327 xx
PASS : xx : XECUTE: TSTART (), NEW (x), TRESTART
       in the transaction, then after it : 2 1|2 0
# Command : $gtm_dist/mumps -run one^ydb1327 xn2
PASS : xn2 : XECUTE: TSTART (x), then an inner XECUTE with an argumentless NEW and the TRESTART
       in the transaction, then after it : 10 1|2 0
# Command : $gtm_dist/mumps -run one^ydb1327 im
PASS : im : XECUTE: TSTART (x), argumentless NEW, implicit restart from a concurrent update (x ^b $TLEVEL after)
       in the transaction, then after it : 10 1|2 5 0
