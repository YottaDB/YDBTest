# [YDB#1101] An @# indirect name or a postconditional that overflows does not fail an assert         #
#----------------------------------------------------------------------------------------------------#

# Each stage feeds the lines shown to "mumps -direct" in a new process, checks that the output has no
# fatal error, and checks for the error that is expected and that the next line of input ran.

# Stage 1 : an exclusive NEW of @a, with a="@#" (the at-hash token, then nothing)
# Command : $gtm_dist/mumps -direct < stage1.inp, where stage1.inp has these lines
#   set a="@#" new (@a)
#   write "end",!
# Before the fix : a Release build issued EXPR. A Debug build failed an assert in indirection.c
# With the fix   : expect EXPR
PASS : no fatal error in stage1.out
PASS : EXPR was issued once, c^zz did not run, and the next line of input ran
----------
Error EXPR seen in stage1.out as expected:
%YDB-E-EXPR, Expression expected but not found
----------
