#-----------------------------------------------------------------------------------------------#
# [YDB#1357] A ZCONTINUE that would QUIT the frame of an active transaction started in Direct   #
# Mode issues TPQUIT once and leaves the transaction active                                     #
#-----------------------------------------------------------------------------------------------#

# A TSTART in Direct Mode makes the frame under the Direct Mode frame the frame of the transaction.
# After a BREAK typed in Direct Mode, or a BREAK in $ZTRAP code or in a ZBREAK, ZSTEP or device
# EXCEPTION action, that frame is not a counted frame, and ZCONTINUE resumes that frame, which then
# QUITs with the transaction active and gets TPQUIT. Before the fix, the error handling after that
# TPQUIT rolled back the transaction (stages 1 to 3, and stage 8, which also left Direct Mode in
# $ZTRAP code), or left Direct Mode in $ZTRAP code with $ECODE set and the transaction active
# (stages 6 and 7, and stages 1 to 3 in YottaDB r2.06 and earlier, which issued TPQUIT twice). With
# the fix, the ZCONTINUE issues TPQUIT before the ZCONTINUE unwinds anything, so the transaction
# stays active and Direct Mode stays at the same level. After a TCOMMIT or TROLLBACK, ZCONTINUE
# works.
#
# Without the fix, stages 1 to 3 and 6 to 8 print FAIL, and stages 4 and 5 PASS.

# Stage 1 : ZCONTINUE after a BREAK in Direct Mode and a TSTART, then TCOMMIT and ZCONTINUE
# Before the fix : TPQUIT, and the transaction was rolled back, so the next line ran with $TLEVEL 0
#                  and the TCOMMIT issued TLVLZERO
# With the fix   : expect TPQUIT once, the next line to run with $TLEVEL 1, and the ZCONTINUE after
#                  the TCOMMIT to work
# Command : $gtm_dist/mumps -direct < zcont.inp, where zcont.inp has these lines
#   break
#   tstart ()
#   zcontinue
#   write "after the first ZCONTINUE $tlevel=",$tlevel,!
#   tcommit
#   zcontinue
#   write "after the second ZCONTINUE $tlevel=",$tlevel,!
PASS : zcont output has after the first ZCONTINUE $tlevel=1
PASS : zcont output has after the second ZCONTINUE $tlevel=0
PASS : zcont output does not have TLVLZERO
PASS : zcont output does not have a fatal error (-F-)
# TPQUIT was issued 1 times
