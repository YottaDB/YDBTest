#----------------------------------------------------------------------------------------------------#

# Each stage creates a database in its own directory, runs the lines shown in a new process, and
# checks that the output has no fatal error and has the lines expected, and the triggers that
# $ZTRIGGER("SELECT") lists at the end.

# Stage 1 : an item whose string subscript has no closing quote, after a longer item that had the
# closing quote at the same place
# Command : $gtm_dist/mumps -direct < stage1.inp, where stage1.inp has these lines
#   write $ztrigger("item","+^b(""ab"") -commands=S -xecute=""write 1"""),!
#   write $ztrigger("item","-*"),!
#   write $ztrigger("item","+^b(""ab"),!
#   write $ztrigger("select"),!
# Before the fix : the third $ZTRIGGER() added +^b("ab") -commands=S -xecute="write 1", made from the
#                  bytes of the first item
# With the fix   : expect Invalid string,
#                  and 0 trigger(s) listed by $ZTRIGGER("SELECT") at the end
PASS : no fatal error in stage1.out
PASS : stage1.out has Invalid string
PASS : $ZTRIGGER("SELECT") lists 0 trigger(s)

#   write $ztrigger("item","+^b(abc=1) -commands=S -xecute=""write 1"""),!

#   write $ztrigger("select"),!
