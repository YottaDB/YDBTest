# [YDB#1269] Test MUPIP INTRPT at a readline direct mode prompt                                                       #
# Direct mode reads through the readline library when ydb_readline is set. A MUPIP INTRPT that arrives while the      #
# process sits in that read makes the signal handler longjmp out of libreadline; readline_read_mval() then saves the  #
# partially typed line, drives $ZINTERRUPT and restores the line on the way back in. An interrupt that arrives when   #
# the process is NOT inside libreadline reaches the same code with nothing to save, and saving libreadline state      #
# there is what caused the SIGSEGV of YDB#1269. An expect script sends MUPIP INTRPT to a mumps -direct process and    #
# verifies that:                                                                                                      #
#   1. an interrupt while a line is partially typed drives $ZINTERRUPT and readline comes back with the line intact   #
#   2. an interrupt that arrives while a command is executing, i.e. outside libreadline, drives $ZINTERRUPT and       #
#      leaves the process at a working prompt                                                                         #
#   3. a burst of interrupts at the prompt leaves the process alive with the prompt still usable                      #
#   4. an interrupt that is still pending when the process first reaches the direct mode prompt, which is             #
#      the SIGSEGV of YDB#1269 itself, runs $ZINTERRUPT and leaves the process at a working prompt                    #
#---------------------------------------------------------------------------------------------------------------------#
