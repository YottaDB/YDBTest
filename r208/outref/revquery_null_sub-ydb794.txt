#----------------------------------------------------------------------------------------------------#
# [YDB#794] Reverse $QUERY() of a global whose last subscript is "" and that has no value returns    #
# the last node at that level with standard null collation                                           #
#----------------------------------------------------------------------------------------------------#

# With standard null collation, $QUERY(^x(...,""),-1) returned the node before ^x(...,"") in
# collation order, which is ^x(...) or a node before it, as "" collates before all other subscripts.
# $QUERY(x(...,""),-1) of a local returned the last node at that level. Now a global returns the last
# node at that level too, when ^x(...,"") has no value. When it has a value, or when the previous
# $QUERY() returned it, it is looked up as is, so a reverse $QUERY() loop that returned it moves on to
# the node before it, even if the loop killed it.
#
# Without the fix, stages 1, 2 and 3 print WRONG. Stages 4 and 5 pass without the fix too; they check
# that locals and GT.M null collation are unchanged. Each check names the result it expects.
#
# Each stage runs in its own process.

# Create a database with these GDE commands. ^x is in DEFAULT, ^a in AREG, which has null subscripts
# disabled, ^c in CREG, which has GT.M null collation, and ^s spans DEFAULT and BREG.
template -region -stdnullcoll -null_subscripts=TRUE
change -region DEFAULT -stdnullcoll -null_subscripts=TRUE
change -segment DEFAULT -file=mumps.dat
add -segment ASEG -file=a.dat
add -region AREG -dyn=ASEG -null_subscripts=FALSE
add -name a -region=AREG
add -segment BSEG -file=b.dat
add -region BREG -dyn=BSEG
add -name s(1:"b") -region=BREG
add -segment CSEG -file=c.dat
add -region CREG -dyn=CSEG -nostdnullcoll
add -name c -region=CREG
# Command : $ydb_dist/yottadb -run setup^ydb794
#   expect each global in the region named above, and each region to have the settings named above
PASS : the region of ^x is DEFAULT
PASS : the region of ^a is AREG
PASS : the region of ^c is CREG
PASS : the region of ^s(2) is BREG
PASS : the region of ^s("c") is DEFAULT
PASS : null subscripts of DEFAULT (1 is ALWAYS) is 1
PASS : null subscripts of AREG (0 is NEVER) is 0
PASS : standard null collation of DEFAULT is 1
PASS : standard null collation of BREG is 1
PASS : standard null collation of CREG is 0

# Stage 1 : $QUERY(gvn,-1) of globals with a trailing null subscript
# Command : $ydb_dist/yottadb -run globals^ydb794
#   expect the last node at that level when ^x(...,"") has no value, and ^x(...,"") looked up as is
#   when it has a value or when the previous $QUERY() returned it
#   previously the node before ^x(...,"") in all cases
PASS : $query(^x(""),-1) is ^x(2,1)
PASS : $query(^x(2,""),-1) is ^x(2,1)
PASS : $query(^x(2,1,""),-1), with no node under ^x(2,1) is ^x(2,1)
PASS : $query(@r,-1) with r="^x("""")" is ^x(2,1)
PASS : $query(^x(3,""),-1) where ^x(3,"") has no value but has a descendant is ^x(3,"",5)
PASS : for  set q=$query(@q,-1) quit:q=""  from q="^x("""")", with a $query() of a local in the loop body, visits is  ^x(3,"",5) ^x(2,1) ^x(1) ^x
PASS : $query(^x(""),-1) where ^x("") has a value is ^x
PASS : a reverse $query() loop from ^x(3) that kills each node whose last subscript is "" visits is  ^x(2,5) ^x(2,"") ^x(1)
PASS : a reverse $query() loop from ^x("z") with a $query(^d) that returns ^d("") in the loop body visits is  ^x("a") ^x(1) ^x("")
PASS : $query(^a(""),-1) in a region with null subscripts disabled is ^a(2,1)
PASS : $query(^s(""),-1) of a global that spans regions is ^s("c")
PASS : $query(^s(2,""),-1) where ^s(2,*) maps to another region is ^s(2,1)

# Stage 2 : ydb_node_previous_s() of a global with a trailing null subscript
# Command : build and run ydb794_sapi.c
#   expect the same results as $QUERY(gvn,-1)
#   previously the node before ^x(...,"")
PASS : ydb_node_previous_s() of ^x("") returned 2 subscript(s) : 2,1
PASS : ydb_node_previous_s() of ^x(2,"") returned 2 subscript(s) : 2,1
PASS : ydb_node_previous_s() of ^x("") where ^x("") has a value returned 0 subscript(s) : 

# Stage 3 : compare $QUERY(lvn,-1) with $QUERY(gvn,-1) over 500 random trees in ^x, and 500 in ^s,
#           which spans regions, of up to 8 nodes with up to 3 subscripts each, for every node and
#           every node with an extra trailing "" subscript, other than a reference whose trailing ""
#           node has a value
# Command : $ydb_dist/yottadb -run random^ydb794
#   expect no differences. Before each pair of calls, a $QUERY() of another local and of a global
#   that does not exist clears the previous results that $QUERY() saves, so that each call is a
#   first call.
#   The fixed seed builds the same trees in every run, so there are 8631 such references in every run.
#   previously the global returned the node before ^x(...,"") where the local returned the last node
#   at that level
PASS : $query(,-1) of all 8631 references matched the global

# Stage 4 : $QUERY(lvn,-1) of locals with a trailing null subscript
# Command : $ydb_dist/yottadb -run locals^ydb794
#   expect the last node at that level when x(...,"") has no value. When x("") has a value, the first
#   call returns the last node, and a call right after a $QUERY() that returned x("") returns the
#   node before it.
#   previously the same results, since the fix does not change locals
PASS : $query(x(""),-1) is x(2,1)
PASS : $query(x(""),-1) where x("") has a value, as the first call is x(2,1)
PASS : $query(x(1),-1) is x("")
PASS : $query(x(""),-1) right after a $query() that returned x("") is x

# Stage 5 : $QUERY(gvn,-1) of a global with GT.M null collation
# Command : $ydb_dist/yottadb -run gtmnull^ydb794
#   expect the last node at that level, and a reverse $QUERY() loop to visit every node once
#   previously the same results, since the fix does not apply to GT.M null collation
PASS : $query(^c(""),-1), the last node at that level is ^c("a")
PASS : for  set q=$query(@q,-1) quit:q=""  from q="^c("""")" visits is  ^c("a") ^c("") ^c(-1) ^c

# Done
