#-------------------------------------------------------------#
# [YDB#1314] A SIGSEGV is reported when the stack cannot grow #
#-------------------------------------------------------------#

# YottaDB installs its signal handlers with SA_ONSTACK, but used to install an alternate signal stack
# only when the process already had one that was smaller than 256 KB, such as the 32 KB one that the
# Go runtime sets up. In a process with no alternate signal stack, a SIGSEGV because the stack cannot
# grow then had no stack for the YottaDB handler to run on, so the kernel killed the process with the
# default action of SIGSEGV, and the process reported nothing. YottaDB now installs its own alternate
# signal stack when there is none.
#
# ydb1314_nogrow.c initializes YottaDB with ydb_set_s(), limits its stack to 8 MiB, then recurses until
# the stack cannot grow. It installs no alternate signal stack of its own.
