# [YDB#1344] Compiling a routine line with an invalid special variable or function name followed by #
# another syntax error issues the errors and produces an object file                                 #
#----------------------------------------------------------------------------------------------------#

# An invalid special variable name (INVSVN) or function name (INVFCN) is a compile time warning, so
# the compiler adds an OC_RTERROR triple and goes on parsing the line. When the line then has a real
# error, ins_errtriple() took that OC_RTERROR triple for an earlier error on the line and left the
# triples of the failed parse after it, which code generation could not handle. The compile ended with
# GTMASSERT2 in emit_code.c (an assert failure in emit_code.c in a Debug build).
#
# Without the fix, stages 1, 2 and 5 end the compile with GTMASSERT2 (or the assert failure), and print
# FAIL, and stages 3, 4 and 6 PASS.
