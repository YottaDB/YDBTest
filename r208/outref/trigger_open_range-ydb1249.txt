# A trigger subscript specification with an open ended range, for example [+^x(sub1=2:)], has an empty
# specification for the open side. Reading the definition back from ^#t used to examine the first byte of
# that empty specification, which is one byte past its end, and act on it when it happened to be a double
# quote, which it is when a quoted field such as the trigger's -xecute text follows. The length then
# underflowed and a valid definition was rejected with
#	%YDB-E-TRIGSUBSCRANGE, Trigger definition for global ^x has one or more invalid subscript range(s)
# or, on a dbg build, failed an assert in gvtr_process_range().
