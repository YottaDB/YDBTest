# [YDB#1342] With $ZTEXIT true, an update that uses an implicit transaction completes once and       #
# then $ZINTERRUPT runs once                                                                         #
#----------------------------------------------------------------------------------------------------#

# A ZTRIGGER command, $ZTRIGGER("ITEM") and a SET or KILL that invokes a trigger use an implicit

#

# repeats without end.
