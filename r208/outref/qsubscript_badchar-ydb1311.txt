#----------------------------------------------------------------------------------------------------#
# [YDB#1311] $QLENGTH() and $QSUBSCRIPT() issue BADCHAR in UTF-8 mode for a name holding a byte      #
# sequence that is not a valid UTF-8 character                                                       #
#----------------------------------------------------------------------------------------------------#

# $QLENGTH() and $QSUBSCRIPT() first check that their argument is a canonic name. In UTF-8 mode that
# check stepped over each non-ASCII character by the length its first byte implies, and did not check
# that the bytes form a valid character, so it accepted such a name. $QSUBSCRIPT() then copied the
# subscript, and for a byte that cannot start a UTF-8 character it wrote past the end of its buffer.
#
# $ZCOLLATE(name,0) and $VIEW("YGVN2GDS",name) use the same check, but do not issue BADCHAR, because the
# reverse $ZCOLLATE(key,0,1) returns a name holding the bytes of a subscript inside quotes as they are.
#
# Without the fix, stage 1 prints WRONG for its first $QLENGTH() and then ends the process with a SIG-11
# (an assert failure in a Debug build) at its first $QSUBSCRIPT(), stage 2 ends the same way at its
# first $QSUBSCRIPT(), stage 4 prints WRONG with NOCANONICNAME for $ZCH(224), where the step over
# the byte skips the closing quote, and stages 3 and 5 PASS.

# Stage 1 : UTF-8 mode, VIEW "BADCHAR"
# Command : $gtm_dist/mumps -run badchar^ydb1311
#   expect $QLENGTH() and $QSUBSCRIPT() to issue BADCHAR for each name, naming its invalid bytes: a
#   continuation byte, a byte that is never valid, a first byte followed by a byte that does not
#   continue it, a first byte followed by the closing quote, a surrogate code point, a bad byte in a
#   subscript after the one asked for, and a global name
PASS : $qlength("x("""_$zchar(128)_""")") issued %YDB-E-BADCHAR, $ZCHAR(128) is not a valid character in the UTF-8 encoding form
PASS : $qsubscript("x("""_$zchar(128)_""")",1) issued %YDB-E-BADCHAR, $ZCHAR(128) is not a valid character in the UTF-8 encoding form
PASS : $qlength("x("""_$zchar(255)_""")") issued %YDB-E-BADCHAR, $ZCHAR(255) is not a valid character in the UTF-8 encoding form
PASS : $qsubscript("x("""_$zchar(255)_""")",1) issued %YDB-E-BADCHAR, $ZCHAR(255) is not a valid character in the UTF-8 encoding form
PASS : $qlength("x("""_$zchar(195,40)_""")") issued %YDB-E-BADCHAR, $ZCHAR(195) is not a valid character in the UTF-8 encoding form
PASS : $qsubscript("x("""_$zchar(195,40)_""")",1) issued %YDB-E-BADCHAR, $ZCHAR(195) is not a valid character in the UTF-8 encoding form
PASS : $qlength("x("""_$zchar(224)_""")") issued %YDB-E-BADCHAR, $ZCHAR(224) is not a valid character in the UTF-8 encoding form
PASS : $qsubscript("x("""_$zchar(224)_""")",1) issued %YDB-E-BADCHAR, $ZCHAR(224) is not a valid character in the UTF-8 encoding form
PASS : $qlength("x("""_$zchar(237,160,128)_""")") issued %YDB-E-BADCHAR, $ZCHAR(237,160,128) is not a valid character in the UTF-8 encoding form
