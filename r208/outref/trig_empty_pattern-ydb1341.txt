# not valid, instead of loading it and then failing every SET of the global with PATCODE             #
#----------------------------------------------------------------------------------------------------#

# The trigger definition parser checked each pattern code after the ? of a pattern subscript, so it
# accepted a ? with no pattern codes after it, and an empty alternation. When the trigger was used,
# the pattern compiler rejected it, so every SET of the global failed with PATCODE until the trigger
# was deleted, and a Debug build failed an assert in gv_trigger.c (0 < len) for an empty pattern.
# The parser now also compiles the pattern the way the trigger code does when the trigger is used.
#
# Stages 1 to 5 each delete all triggers, load a trigger on ^x with a pattern subscript and the code
# set ^y=$get(^y)+1, then SET ^x(1), ^x("a"), ^x("bc") and ^x("de"), and check the number of times
# the trigger ran. Each stage runs in its own process.
